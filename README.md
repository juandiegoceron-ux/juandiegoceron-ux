### 🚀 Proyectos Destacados (En Producción)

#### 🥇 [NutriCoach Pro](https://nutricoach-eight.vercel.app/)
**Plataforma SaaS integral para Coaches de Fitness y Nutrición.**
* **Qué es:** Un ecosistema completo que permite a los entrenadores gestionar clientes, automatizar planes nutricionales (macros), crear rutinas interactivas y visualizar métricas de progreso.
* **Features clave:** Portal dual (Coach/Cliente), generación automática de PDFs con marca blanca, integración de pagos (PayPal), seguridad de grado bancario (JWT) y diseño 100% responsivo.

#### 📦 [Inventario Web Pro](https://inventario-web-pro.vercel.app/)
**Sistema avanzado de gestión de inventario en la nube.**
* **Qué es:** Aplicación web moderna orientada a la administración de stock, ventas, etc. en tiempo real. 
* **Features clave:** Arquitectura rápida basada en Vite, UI moderna y limpia (tipografía Outfit), optimizada para operaciones CRUD masivas y experiencia de usuario sin fricciones.

#### 📱 [INV. PRO - App Móvil (Reto Técnico)](https://github.com/juandiegoceron-ux/tum-flutter-challenge)
**Aplicación móvil de gestión de inventario.**
* **Qué es:** Proyecto nativo desarrollado en Flutter conectado a una base de datos real.
* **Features clave:** Autenticación en tiempo real con Supabase, UI/UX Premium con Glassmorphism, Hero Animations fluidas, Modo Oscuro elegante y entorno totalmente contenedorizado con Docker.
